
# OutdoorFit — планировщик тренировок на открытом воздухе

## О проекте

OutdoorFit — учебное веб-приложение для планирования тренировок на открытом воздухе в Санкт-Петербурге.

Приложение помогает пользователю создавать планы тренировок, учитывать погодные условия и отслеживать подготовку с помощью интерактивного чек-листа.

## Основные возможности

- Создание тренировок для бега и занятий на спортивной площадке.
- Учёт тренировок в тёмное время суток.
- Динамический чек-лист подготовки.
- Отображение прогресса подготовки в процентах.
- Сохранение, редактирование и удаление тренировок.
- Хранение данных в localStorage браузера.
- Получение актуальных погодных данных через Open-Meteo API.
- Рекомендации с учётом температуры, осадков и ветра.
- Ссылки на информационные источники.
- Формирование и печать отчёта о тренировке.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- localStorage

## Структура проекта

- index.html — структура веб-страницы.
- styles.css — оформление интерфейса.
- data.js — справочные данные, чек-лист и рекомендации.
- main.js — создание, сохранение и управление тренировками.
- weather.js — получение погоды и формирование погодных рекомендаций.
- README.md — документация проекта.

## Запуск приложения

1. Скачать файлы проекта.
2. Открыть папку проекта в Visual Studio Code.
3. Запустить index.html с помощью расширения Live Server.
4. Приложение откроется в браузере.

Для загрузки погодных данных необходимо подключение к интернету.

## Хранение данных

Тренировки сохраняются в localStorage браузера.

Данные доступны после обновления страницы, но могут быть удалены при очистке данных браузера.

## Ограничения

Погодные данные зависят от доступности внешнего API.

Рекомендации носят информационный характер и не гарантируют безопасность тренировок.
